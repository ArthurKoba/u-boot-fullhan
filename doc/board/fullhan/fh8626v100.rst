FH8626V100 / ANJIA AJL33PQ0866
==============================

FH8626V100 is an ARM1176-based Fullhan camera SoC.  The validated ANJIA
AJL33PQ0866 implementation provides 64 MiB SDRAM, DesignWare APB UART/timer,
two DesignWare GPIO banks, SPI NOR and DesignWare Ethernet in RMII mode.
Linux is started with legacy ATAGs and machine ID 9999 as required by the
current FH8626V100 Linux 4.9 platform.

The implementation is split conceptually into reusable FH8626V100 SoC support
and board-specific AJL33PQ0866 data.  The recovered DDR/Boot-ROM container,
RMII pad setup and persistent-flash migration contract must not be assumed to
apply to another FH8626V100 board without independent validation.

Configurations
--------------

``fh8626v100_flash_defconfig``
    OpenIPC-native production target linked at ``0xa0800000``.  The Fullhan
    ROM container loads it from NOR offset ``0x10000``.  Persistent environment
    is stored at the OpenIPC offset ``0x40000``.

``fh8626v100_ram_defconfig``
    Non-persistent migration/recovery target linked at ``0xa3000000``.  It is
    intentionally richer and enables the limited factory-U-Boot compatibility
    helpers used while transitioning an installed board.

OpenIPC 8 MiB NOR contract
--------------------------

The production target follows the standard OpenIPC 8 MiB layout::

    spi_flash:256k(boot),64k(env),2048k(kernel),5120k(rootfs),-(rootfs_data)

The corresponding offsets are:

=================  =====================
NOR range          Purpose
=================  =====================
``0x000000-03ffff`` OpenIPC ``boot``
``0x040000-04ffff`` U-Boot environment
``0x050000-24ffff`` Linux legacy uImage
``0x250000-74ffff`` SquashFS root filesystem
``0x750000-7fffff`` persistent ``rootfs_data``
=================  =====================

FH8626V100 has a board-specific split inside the standard 256 KiB boot
partition::

    0x000000-0x00ffff   Fullhan Boot ROM data container
    0x010000-0x03ffff   U-Boot payload

The environment remains outside that boot partition at ``0x40000`` exactly as
expected by the OpenIPC 8 MiB layout.

The production default environment exposes OpenIPC-style ``mtdpartsnor8m``,
``setnor8m``, ``bootcmdnor``, ``uknor8m`` and ``urnor8m`` commands.  The normal
kernel name is ``uImage.${soc}``, rootfs is ``rootfs.squashfs.${soc}``, and
Linux mounts ``/dev/mtdblock3`` as SquashFS.

The kernel partition is exactly 2 MiB.  A native-layout migration must not be
attempted until the final OpenIPC ``uImage.fh8626v100`` has been measured and
confirmed to fit that partition.

Fullhan ROM container
---------------------

The Fullhan mask ROM does not execute U-Boot directly.  It interprets a 64 KiB
board data container which initializes DDR and describes the U-Boot payload.
Recovered AJL33PQ0866 data is represented by
``board/fullhan/fh8626v100/bootrom.json``.

``tools/fh8626_bootchain.py`` remains the stock-container
parser/reconstruction oracle.  ``tools/fh8626_openipc_boot.py`` builds the
production OpenIPC boot partition by preserving the recovered board data and
changing the U-Boot descriptor to the native layout:

* flash offset ``0x10000``;
* fixed 192 KiB ROM-visible U-Boot envelope;
* load address ``0xa0800000``;
* entry address ``0xa0800000``.

The remaining recovered container fields are retained until their mask-ROM
semantics are better established.  The container is board data, not a copied
vendor U-Boot executable.

Build
-----

Build all release/recovery artifacts with::

    CROSS_COMPILE=arm-linux-gnueabi- ./build.sh

The output directory contains:

``u-boot-fh8626v100-anjia-ajl33pq0866.bin``
    Exact 256 KiB OpenIPC ``boot`` partition.

``u-boot-fh8626v100-anjia-ajl33pq0866-bootstrap.bin``
    64 KiB generated Fullhan ROM container.

``u-boot-fh8626v100-anjia-ajl33pq0866-uboot.bin``
    192 KiB padded U-Boot payload loaded by the ROM container.

``u-boot-fh8626v100-anjia-ajl33pq0866-raw.bin``
    Raw linked production U-Boot binary.

``u-boot-fh8626v100-anjia-ajl33pq0866-ram.bin``
    Non-persistent RAM migration/recovery build.

``SHA256SUMS``
    SHA-256 hashes of all emitted binaries.

RAM validation
--------------

Before persistent migration, chainload the RAM target from the installed
bootloader::

    tftpboot 0xa3000000 u-boot-fh8626v100-anjia-ajl33pq0866-ram.bin
    crc32 0xa3000000 ${filesize}
    go 0xa3000000

Initial validation is read-only.  Verify serial, DRAM, GPIO, SPI NOR and
Ethernet before any erase/write operation.  The RAM target carries
``CONFIG_FH8626V100_STOCK_COMPAT`` so the migration workflow can still use the
factory ``kload`` shortcut and ``gpio <pin> out <0|1>`` syntax when useful.
The production target does not carry those interfaces.

Migration
---------

The old Fullhan geometry is not the target architecture.  Moving an installed
camera to OpenIPC-native layout is a one-time full-flash-layout transition:

* stock environment at ``0x10000`` is discarded;
* U-Boot moves from ``0x20000`` to ``0x10000``;
* OpenIPC environment is created at ``0x40000``;
* kernel remains at ``0x50000`` but its partition becomes 2 MiB;
* rootfs moves to ``0x250000``;
* rootfs_data becomes the remainder from ``0x750000``.

The complete checked procedure is documented in
:doc:`fh8626v100-openipc-migration`.  Kernel and rootfs must be written and
verified before the final boot partition is installed and the camera reset.

The earlier stock-compatible U-Boot-only replacement remains documented in
:doc:`fh8626v100-stock-migration` as historical evidence and a recovery aid.
It is not the final OpenIPC architecture.

Hardware evidence
-----------------

``HARDWARE_PASS`` for the underlying port includes:

* RAM chainload on ARM1176;
* UART and 64 MiB DRAM;
* both GPIO banks;
* repeated SPI NOR reads at 50 MHz;
* legacy-image verification/kernel handoff;
* RMII PHY identification, 100 Mbit/s full-duplex link, ping and TFTP;
* persistent SPI environment access;
* cold boot through the recovered Fullhan boot chain;
* successful OpenIPC boot through the earlier compatible layout.

The new OpenIPC-native relocation (U-Boot ``0x10000``, env ``0x40000``, rootfs
``0x250000``) remains ``SOURCE/BUILD CANDIDATE`` until a complete migrated
image cold-boots on the physical AJL33PQ0866.  Do not promote that state based
only on packer tests or successful compilation.
